手把手教你注册使用 OpenAI

发表于2022-12-26|更新于2023-11-17|日记
|阅读量:

最近大火的要属于 OpenAI ，但是要使用 OpenAI 的服务和资源，您需要先在 OpenAI 网站上注册一个帐户。注册过程是免费的。但是由于 OpenAI 目前还没有向全世界开放使用，国内想使用 OpenAI ，就必须用其它国家的短信验证手机号。

在注册的时候，提示需要手机号验证，注意，用谷歌语音虚拟手机号，也是不行的，所以建议使用 https://sms-activate.org/ 网站先去注册一个账号，然后点击右上角用支付宝充值1美金。相当与70卢布。

注册流程：

  1. 打开 OpenAI 网站（https://openai.com）并点击右上角的“注册”按钮。
  2. 填写所需的信息，包括您的电子邮件地址和密码。
  3. 阅读并同意 OpenAI 的服务条款和隐私政策。
  4. 点击“注册”按钮完成注册过程。注册完成会提示手机号验证。

验证流程：

  1. 登录 https://sms-activate.org/ 充值1美金，选择用支付宝即可。
  2. 在左边填入 OpenAI ，即可搜索，选择印度的即可（印度的验证价格比较便宜），选择购买1个即可。
  3. 然后登陆（https://openai.com），填入购买的手机号，验证手机号，这时候 https://sms-activate.org/ 会收到验证码，填入即可。

这时候，您就可以使用您的 OpenAI 帐户登录 OpenAI 网站并访问各种服务和资源，包括 GPT 系列语言模型、训练数据集和深度学习框架。
