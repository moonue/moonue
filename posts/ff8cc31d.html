腾讯云服务器上安装 docker 和 Docker compose

发表于2022-09-30|更新于2023-03-03|Docker
|阅读量:

先决条件

要成功安装 Docker Desktop，您必须：

  • 满足系统要求
  • 拥有 Ubuntu Jammy Jellyfish 22.04 (LTS) 或 Ubuntu Impish Indri 21.10 的 64 位版本。x86_64（或amd64）架构支持 Docker Desktop 。
  • 卸载 Docker Desktop for Linux 的技术预览版或 beta 版。运行：

sudo apt remove docker-desktop

要彻底清理，请删除位于 的配置和数据文件$HOME/.docker/desktop、位于 的符号链接/usr/local/bin/com.docker.cli，并清除剩余的 systemd 服务文件。

rm -r $HOME/.docker/desktop
sudo rm /usr/local/bin/com.docker.cli
sudo apt purge docker-desktop

笔记

如果您已安装 Docker Desktop for Linux 技术预览版或 beta 版，则需要删除由这些包生成的所有文件（例如，、、~/.config/systemd/user/docker-desktop.service）~/.local/share/systemd/user/docker-desktop.service。

此外，对于非 Gnome 桌面环境，gnome-terminal必须安装：

sudo apt install gnome-terminal

安装 curl

whereic curl

Or 没有就安装curl

sudo apt-get install -y curl

更新 Ubuntu 服务器

sudo apt-get update

安装 docker 代码

apt install docker.io

查看 docker 安装的版本

docker version

安装 docker compose 代码

apt install docker-compose

查看 docker compose 安装的版本

docker-compose version

运行第一个容器

sudo docker run ubuntu echo ‘Hello world’
